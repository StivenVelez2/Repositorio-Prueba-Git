# Mi Proyecto de Git
lo que trata este proyecto es una prueba de comandos de git
lo que significa cada comando de git segun yo:
git init: funciona para inicializar un proyecto con git 
git status: funciona para mirar  el estado del proyecto con sus cambios y modificaciones
git add: sirve para agregar los archivos modificados 
git commit: sirve para comentar los cambios que vamos a subir al repositorio
git push: sirve para subir los cambios hacia el repositorio de git
git branch: sirve para crear, listar o eliminar ramas  
git diff: sirve para ver que cambios hay respecto al ultimo commit
git checkout: sirve para cambiar entre ramas 
git log: sirve para ver el historial de cmabios en el commit 
git restore: sirve para deshacer cambios en un archivo sin necesidad de borrar nada
